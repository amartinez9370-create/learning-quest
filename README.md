# Learning Quest

An illustrated fantasy adventure for mastering Grade 4 subjects, aligned to the MATATAG curriculum.

Play at: https://amartinez9370-create.github.io/learning-quest/

## Structure
- `index.html` — the app itself
- `assets/regions/` — region overworld map art
- `assets/locations/` — individual location map art (rendered, per-subject scenes)
- `assets/npcs/` — NPC character sprites
- `assets/players/` — player character sprites (front/back, per gender option)

🚧 Under active development. Currently: Windy Plains (Term 1), 8 subjects, 570 questions.
